# job-search-data (private)

Working files for the `CptnHook/job-search` workspace: the tracker, `documents/`, application drafts, company research, and Gmail sync state. That repo git-ignores them, so they live here instead.

Don't edit by hand. In a job-search session run `python3 tools/cloud_session.py start` to restore these files and `python3 tools/cloud_session.py save` to commit and push changes. See `CLOUD.md` there.

This repo holds personal data. Keep it private.
